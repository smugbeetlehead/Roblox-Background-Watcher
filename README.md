# Usage
### Automatically removes roblox from running in background
# How to enable this

### copy the texts in <roblox-watcher.txt> file.
### open notepad, and paste
### Click on 'file', click on 'save as'
### name the file 'roblox-watcher.ps1'
### click on 'all files' and save
### Right click + shift on the file
### click on 'copy as path'
### press windows + r
### type 'taskschd.msc' and enter
